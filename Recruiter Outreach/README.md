# Recruiter Outreach

Find recruiters and prepare LinkedIn drafts for you to review and send. Outreach uses its own contact tracker.

## Set up

Follow [onboarding](ONBOARDING.md) to confirm target roles, your LinkedIn identity, private storage and a local JSON or Google Sheets [tracker](tracker.md). Review your message copy, then request a research pilot followed by a separate pilot of up to two drafts.

## Run

1. Request [research](research.md) for named companies. Review the contacts and evidence.
2. Separately request [drafts](run.md) for a company or named contacts and specify a count. The agent checks history and leaves the drafts open.
3. Review the drafts, attach any resume and send them yourself. Tell the agent which ones you sent so it can update their history.

## Change preferences

Use [onboarding](ONBOARDING.md#change-preferences) to change your targets, copy or tracker settings.
