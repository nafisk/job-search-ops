# Application Workflow

Verify jobs from your selected sources and save them to one tracker. You can also track applications and interviews from selected sources.

## Set up

Read the [operating rules](docs/operations.md) and follow [onboarding](ONBOARDING.md). Reuse the user's private setup and verify access for each selected source.

| Source | Setup |
| --- | --- |
| LinkedIn alerts | [Verify Gmail delivery](docs/linkedin-alerts.md) |
| Referral portals | [Choose companies and referral holds](docs/referrals.md) |
| Blind company research | [Choose companies and verify the handoff](<../Blind Company Research/ONBOARDING.md>) |

## Run

Follow the [central runbook](run.md) in the configured chat. The helpers check sources. The central chat verifies postings, saves them and reports coverage gaps. Blind can run separately and queue results for the next central run.

## Change settings

Use [preferences](docs/preferences.md) for criteria, tracking, reports or schedules. Use [discovery export](docs/discovery-export.md) to switch the three-tab job list between Local Excel and Google Sheets. Update the **Application status** dropdown by hand.

See the [guide index](docs/source-map.md) for other procedures.
