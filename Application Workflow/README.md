# Application Workflow

Find jobs from LinkedIn alerts, referral portals, or [Blind company research](<../Blind Company Research/README.md>). The main workflow session saves verified jobs to one tracker and can track applications and interviews from the sources you choose.

## Set up

Read the [operating rules](docs/operations.md), then follow [onboarding](ONBOARDING.md). Check the [required tools](docs/tools.md) for the selected features. Ask for an existing private setup before starting a new one. Reuse confirmed choices and check access only for selected sources.

| If the user selects | Follow |
| --- | --- |
| LinkedIn alerts | [Set up and verify Gmail delivery](docs/linkedin-alerts.md) |
| Referral portals | [Set up the company list and referral holds](docs/referrals.md) |
| Blind company research | [Choose rated companies and set up the handoff](<../Blind Company Research/ONBOARDING.md>) |

## Run

Follow the [main runbook](run.md) in the configured chat. The selected helpers research jobs. The main chat checks their findings, saves them, and reports gaps. Blind can run separately, with results waiting for the main chat to save them.

## Change settings

Use [preferences](docs/preferences.md) for search criteria, tracking, reports, or schedules. Use [discovery export](docs/discovery-export.md) to choose Local Excel or Google Sheets for the three-tab copy of saved postings. Use its Application status dropdown to track your applications by hand.

For other procedures, use the [guide index](docs/source-map.md). Start [Application Batches](<../Application Batches/README.md>) or [Recruiter Outreach](<../Recruiter Outreach/README.md>) on a separate request.
