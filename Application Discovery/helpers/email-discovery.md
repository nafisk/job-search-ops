# Email alert discovery producer

Use the `main` gate in the [shared source checks](../docs/operations.md#start-a-discovery-source). Read the private config, checkpoints and retry history. Use native Gmail reads for the selected account and public pages for job verification. Keep labels and read state intact. The coordinator writes the tracker and delivers the brief.

Read the [setup evidence](../docs/linkedin-alerts.md#5-verify-delivery-and-hand-off-to-discovery), usually `evidence/linkedin-alerts-setup.md`. Reuse valid proof of delivery and routing, and recheck it after relevant changes. Report missing proof or pending first delivery. A source with verified setup can have an empty window. Alert and filter changes belong to setup.

1. **Freeze the window.** Verify the Gmail identity, then use the last fully accounted checkpoint minus 48 hours through the fixed cutoff. With no checkpoint, use the configured lookback (default seven days). Process missed time in seven-day windows, oldest first, and include older unresolved items.
2. **Search Gmail.** Run separate bounded queries for the configured label and observed senders/subjects, including other selected alert services such as Simplify. Include archived and read messages. Follow every page token, detect loops, count queries and pages, and union by **message ID**. Resolve discrepancies with focused queries within the [attempt budget](../docs/operations.md#start-a-discovery-source).
3. **Inventory and screen.** Read all relevant MIME parts and full decoded HTML and plain text, including secondary recommendations. Follow [alert extraction](../support/toolkit/ALERTS.md) for independent review and the per-card manifest. Collapse repeated cards for one role within a message. Keep distinct messages as separate sightings with `email:<message-id>:<source-job-id>` identities. Retain safe observed links and verified aliases. [Screen each item](../support/toolkit/SCREENING.md) using the full exact posting. For Simplify, keep the verified match or posting link.
4. **Hand off.** Send the `email` packet through the [shared handoff](../docs/handoffs.md#producer-handoff), with counts, gaps and the resume cursor. Report zero matches only after accounting for every message and card. Advance a complete window with the coordinator.

Keep raw mail and private IDs in the installation. Use [the source boundaries](../docs/operations.md#ownership-and-source-boundaries) for account access and authorization.
