# Application Discovery

Verify jobs from your selected sources and save them to one tracker. You can also track applications and interviews from selected sources.

## Set up

Read the [operating rules](docs/operations.md) and follow [onboarding](ONBOARDING.md). Reuse the user's private setup and verify access for each selected source.

| Source | Setup |
| --- | --- |
| Gmail job alerts | [Verify LinkedIn alert delivery](docs/linkedin-alerts.md) |
| Referral matching and portal searches | [Save your referral list and optional searches](docs/referrals.md) |
| [Blind company research](<Blind Company Research/README.md>) | [Choose companies and verify the handoff](<Blind Company Research/ONBOARDING.md>) |

## Run

Follow the [central runbook](run.md) in the configured chat. A coordinated run checks Gmail alerts and Blind, matches verified jobs to your referral list, and saves to one tracker. To check a specific employer's portal, request a [targeted run](helpers/referral-portals.md).

## Change settings

Use [preferences](docs/preferences.md) for criteria, tracking, reports or schedules. Use [discovery export](docs/discovery-export.md) to switch the three-tab job list between Local Excel and Google Sheets. Update the **Application status** dropdown by hand.

See the [guide index](docs/source-map.md) for other procedures and the [cutover guide](docs/upgrade-and-recovery.md#adopt-existing-scheduled-work) for existing schedules. For a setup that predates the folder rename, [check saved repository paths](docs/upgrade-and-recovery.md#update-saved-repository-paths).
