# Application Discovery

Find jobs and save verified matches to a shared Excel or Google Sheets tracker.

| Start here | What to use |
| --- | --- |
| Set up discovery or application tracking | [Onboarding](ONBOARDING.md) |
| Run discovery or tracking | [Main runbook](run.md) |
| Check a named employer | [Referral portal search](helpers/referral-portals.md) |
| Run Blind research separately | [Blind runbook](<Blind Company Research/run.md>) |
| Change filters, sources or timing | [Preferences](docs/preferences.md) |
| Export saved jobs | [Discovery export](docs/discovery-export.md) |

In coordinated mode, Gmail job alerts and Blind research use the same search profile. The coordinator saves both sets of results and checks the optional referral list after deduplication.

For an existing deployment, see the [cutover checklist](docs/upgrade-and-recovery.md#adopt-existing-scheduled-work). The [guide index](docs/source-map.md) lists the remaining procedures.
