# Application Batches

Open application pages for eligible jobs in the shared tracker. You fill and submit the applications.

## Set up

Complete the shared [Application Discovery setup and pilot](<../Application Discovery/ONBOARDING.md>). Give the agent your private configuration path and follow [batch onboarding](ONBOARDING.md) to confirm criteria, browser profile, operating chat, ledger and limits. The defaults are five pages per request and twenty outstanding.

## Run

Ask the batch chat to follow the [runbook](run.md) and open your first batch. It recovers earlier tabs, checks capacity, rechecks saved jobs and referral holds, and opens eligible employer or ATS pages.

Say **“Next five”** in the same chat to open more pages within your limit. Say **“Check all submissions”** to reconcile registered applications using the selected [tracking sources](<../Application Discovery/docs/tracking.md>). Only submission evidence can establish that you applied.

## Change preferences

Use [batch onboarding](ONBOARDING.md#change-preferences) for limits, browser or chat ownership. Use [Application Discovery preferences](<../Application Discovery/docs/preferences.md>) for role criteria or tracking sources.
