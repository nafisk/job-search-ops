# Evidence and labels

Inventory qualifications across the complete description. Quote only necessary job wording and cite resume sections for applicant claims.

| Evidence state | Meaning |
| --- | --- |
| Supported | A resume bullet, project, date range, degree, or user statement supports the exact requirement. |
| Transferable | Analogous experience; explain the difference. It does not establish a mandatory credential or specialty tenure. |
| Unknown | Missing, ambiguous, unreadable, or insufficiently specific. Resume silence is not proof of absence. |
| Unmet | Explicit applicant facts conflict with the requirement. |

| Overall label | Use when |
| --- | --- |
| Strong match | Primary work/desired criteria align; all material required qualifications are supported; no material conflict is known. Preferred gaps may remain. |
| Plausible match | Primary work aligns and material requirements are supported, with preferred gaps, competitive seniority concerns, or a supported equivalent pathway. |
| Needs clarification | Unknown material required qualifications, incomplete descriptions, unclear duties, or contradictory location policies prevent a defensible conclusion. |
| Mismatch | A verified mandatory conflict or primary-duty/location mismatch exists. Name it; do not convert missing facts into conflicts. |

Evaluate OR branches separately and combine common AND requirements with each branch. Use only degrees actually held. Preferred years never become required years. Search ceilings do not prove applicant tenure. Total experience cannot prove C++, Kubernetes, or leadership years.

Fictional example: Alex has three years of Java API work and a CS bachelor's. A posting requires two years Java, prefers five years Kafka, and requires a license absent from the resume. Java is supported, Kafka is unknown/preferred, and the license is unknown/required: needs clarification. If Alex confirms no license and no alternative is allowed, it becomes mismatch. If the license is confirmed held, the preferred Kafka gap can support plausible match.
